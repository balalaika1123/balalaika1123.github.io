Подготовка и публикация коротких видео

Mathseed Video Factory помогает владельцу канала @mathseed готовить ролики, публиковать Shorts и просматривать показатели своих публикаций.

Это личное приложение для канала владельца. Самостоятельная регистрация сторонних пользователей на этом сайте не предусмотрена.

Что делает приложение

  • Готовит видео и сопровождающие материалы: название, описание и теги.
  • После подключения выбранного канала загружает видео через официальный YouTube Data API в соответствии с настройками владельца.
  • Проверяет канал, сохраняет результат загрузки и собирает доступную статистику публикаций через YouTube Data API и YouTube Analytics API.

Доступ остаётся под контролем владельца

Подключение выполняется на странице согласия Google. Приложение получает разрешения для выбранного канала; пароль Google в него не передаётся.

Владелец управляет работой системы в своей закрытой панели. Доступ приложения к Google можно отозвать в настройках подключений Google. Эта публичная страница не предоставляет доступ к панели или данным канала.

О данных и правилах

Перед подключением ознакомьтесь с политикой конфиденциальности и условиями использования. В них описаны запрашиваемые разрешения, хранение данных и порядок отзыва доступа.

Владелец проекта — владелец канала @mathseed. Вопросы по работе приложения и обработке данных следует направлять владельцу через этот канал.
